You are a senior full-stack developer and product designer.

Your task is to design and build a modern web application called **GitVitals**.

GitVitals is a free developer tool that analyzes **both GitHub repositories and GitHub profiles** and generates visual insights about activity, structure, and health.

The application must be minimalistic, elegant, and modern with a dark theme UI.

Focus on clean design, smooth animations, and clear developer insights.

--------------------------------------------------

PRODUCT NAME

GitVitals

Tagline:
"Understand GitHub repositories and developer profiles in seconds."

--------------------------------------------------

PRODUCT PURPOSE

GitVitals allows users to analyze:

1) GitHub repositories  
2) GitHub developer profiles

The system should generate clear insights about:

repository health  
project activity  
developer productivity  
open source contribution patterns

The UI should transform GitHub data into **visual, easy-to-understand insights.**

--------------------------------------------------

MAIN USER FLOW

Landing page contains two analysis modes:

1️⃣ Repository Analysis  
2️⃣ Profile Analysis

User options:

• paste repository URL  
• paste GitHub profile URL  
• enter GitHub username

Example inputs:

Repository:
https://github.com/vercel/next.js

Profile:
https://github.com/gaearon

or

username:
gaearon

REPOSITORY ANALYSIS FEATURES

When a repository is analyzed, display the following sections.

Repository Overview

• Repository name  
• Owner  
• Description  
• Creation date  
• Last updated date  
• Default branch  
• License type  
• Repository size  

Activity Metrics

• Total commits  
• Commits last 30 days  
• Commits last 90 days  
• Average commits per month  
• Last commit date  

Visualization:

commit activity graph

--------------------------------------------------

Contributors Analysis

• total contributors  
• top contributors  
• contribution distribution  
• contributor ranking  

Estimate a **Bus Factor**

Bus Factor = number of developers responsible for majority of commits.

--------------------------------------------------

Language Distribution

Example:

JavaScript 65%  
TypeScript 20%  
CSS 10%  
HTML 5%

Visualization:

donut chart

--------------------------------------------------

Popularity Metrics

• Stars  
• Forks  
• Watchers  
• Open issues  
• Closed issues  
• Pull requests  

--------------------------------------------------

Maintenance Health

• Issue resolution speed  
• Pull request merge rate  
• Average review time  

--------------------------------------------------

Codebase Insights

• estimated lines of code  
• number of files  
• directory structure depth  

--------------------------------------------------

Repository Health Score

Calculate a score between **0 and 100**.

Factors:

commit frequency  
recent activity  
contributor diversity  
issue resolution speed  
repository popularity  

Score levels:

90–100 → Excellent  
75–89 → Healthy  
50–74 → Moderate  
30–49 → Risky  
0–29 → Inactive
