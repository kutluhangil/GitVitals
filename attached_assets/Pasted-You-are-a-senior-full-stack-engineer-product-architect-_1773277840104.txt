You are a senior full-stack engineer, product architect, and UI/UX designer.

Your task is to design and build a modern developer analytics web application called **GitVitals**.

GitVitals is a free developer tool that analyzes **GitHub repositories and GitHub developer profiles** and transforms GitHub data into clear insights, visual metrics, and health scores.

The platform should feel like a professional SaaS developer tool similar to GitHub Insights, Vercel Analytics, or Linear.

Focus on:

- clean architecture
- minimalist UI
- developer-friendly experience
- fast data analysis
- visually rich insights

--------------------------------------------------

PRODUCT NAME

GitVitals

Tagline:

"The health check for GitHub."

Alternative tagline:

"Understand repositories. Measure developers."

--------------------------------------------------

PRODUCT CORE PURPOSE

GitVitals helps developers, recruiters, and teams quickly evaluate:

• the health of a GitHub repository  
• the activity of a project  
• the productivity of a developer  
• the technology stack used  
• the risk level of a project  

The platform converts GitHub data into **actionable insights and visual analytics.**

--------------------------------------------------

MAIN FEATURES

GitVitals must include the following core features:

1️⃣ Repo Analyzer  
2️⃣ Profile Analyzer  
3️⃣ Developer Score  
4️⃣ Repo Risk Score  
5️⃣ Tech Stack Detector  
6️⃣ Repo Comparison  
7️⃣ Shareable Developer Card  

Each feature must integrate smoothly into the platform.

--------------------------------------------------

MAIN USER FLOW

1. User opens the GitVitals website.
2. User pastes either:
   - a GitHub repository URL
   - a GitHub profile URL
   - a GitHub username
3. User clicks "Analyze".
4. A loading animation appears.
5. The system fetches GitHub API data.
6. Results appear gradually with animated sections.
7. The user can export the report or share results.

FEATURE 3 — DEVELOPER SCORE

Calculate a **Developer Score from 0 to 100**.

Factors include:

• total repositories  
• total stars received  
• contribution frequency  
• consistency of commits  
• open source collaboration  
• number of contributors in repos  

Score levels:

90-100 → Elite Developer  
75-89 → Advanced Developer  
50-74 → Active Developer  
25-49 → Beginner  
0-24 → Inactive

Display the score visually using a circular progress meter.

Example:

Developer Score: 84 / 100
